Project documentation

Milestone 2 topic and subtopics, presented as an interactive project overview.

1. Project overview

Problem: personal expenses can be difficult to track consistently.

Solution: a menu-driven expense analyzer that stores records and produces spending summaries. Each record contains date, amount, category, and description.

2. Objectives & features

  • Add expenses with validated amount and category.
  • Save and reload records using CSV.
  • View all expense records.
  • Calculate total expenses and remaining budget.
  • Show category totals and highest-spending category.
  • Warn when spending exceeds budget.

3. Program workflow

1
Enter a positive monthly budget.
2
Load previously saved expense records.
3
Add expenses, view records, or view summary.
4
Return to the menu or exit the application.

4. Python concepts used

  • Variables and numeric data types.
  • Lists and dictionaries for records.
  • Functions for reusable tasks.
  • if/elif/else and while loops.
  • csv and os modules for file storage.
  • datetime.date for dates.
  • try/except for invalid input and file errors.

5. Core calculations

  • Total expenses = sum of recorded amounts.
  • Remaining budget = entered budget − total expenses.
  • Category totals are accumulated in a dictionary.
  • Highest-spending category has the largest total.
  • Spending above budget triggers an alert.

6. Testing & verification

The project report records 8 tests passed, 0 failures using python -m unittest -v.

Coverage: totals, remaining budget, exact-budget boundary, exceeded budget, category totals, highest category, empty records, and CSV save/load. Manual checks should include invalid amount and invalid menu choice.

7. Team contributions

8. Limitations & future scope

The current Python summary uses all CSV records and does not filter to the current calendar month.

  • Month-wise filtering.
  • Edit/delete records.
  • Graphical charts.
  • Exportable summaries.
  • Graphical user interface.

9. Conclusion

The project demonstrates Python fundamentals and file handling by converting individual expense entries into budget and category summaries. The automated tests are reported as passing; the team should understand each function before the viva.

Implementation note: This website is an interactive browser-based companion to the Python project. It includes month filters, edit/delete, charts, and CSV import/export as website enhancements; these should not be confused with features already implemented in the original Python program.
